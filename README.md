# The Presidency — Premium Concept Redesign v2.0

A fully working, production-grade static multi-page concept for a modern redesign of **The Presidency of the Republic of South Africa**.

## 🚀 Features

- **Premium Typography**: DM Sans + Playfair Display + JetBrains Mono
- **Design System**: Full color tokens, spacing scale, shadow system
- **Dark Mode**: Persistent theme preference with localStorage
- **Accessibility**: WCAG 2.1 AA+ compliant, skip links, ARIA labels, keyboard navigation
- **Responsive**: Mobile-first, tablet and desktop breakpoints
- **Search**: Site-wide search overlay with Ctrl+K shortcut
- **Filtering**: Real-time filtering on news, speeches, and procurement pages
- **Animations**: Scroll-triggered reveal, smooth hover states
- **Font Scaling**: Accessibility controls for text size
- **Toast Notifications**: User feedback system
- **Print Styles**: Optimized for printing
